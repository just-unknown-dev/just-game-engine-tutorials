# 02 Install and create your first project

After this episode, you have the just tool installed, a game made with just create, and it running on its own and with the level editor over it.

Docs: https://engine.justunknown.com/docs/installation

## my_game/

The game `just create my_game` makes.

```text
cd my_game
just game run --editor     # the game with the editor (desktop)
just game run              # the game
flutter test
```

The `just` tool installs with `dart pub global activate just_core_cli` (episode 02).
