# 03 Your first game in code

After this episode, you can make an engine, add entities with shapes and movement, show it in Flutter, and drop a ball onto a floor with physics. You know the engine's lifecycle.

Docs: https://engine.justunknown.com/docs/quick-start

## first_game/

A Flutter app with the engine: two programs, each as on screen, and their tests.

| Program | What it shows | Run it |
|---|---|---|
| `lib/main.dart` | The first program: an engine and its first entities, shown in Flutter. | `flutter run` |
| `lib/ball.dart` | The floor and the ball. | `flutter run -t lib/ball.dart` |

```text
cd first_game
flutter run
flutter test
```
